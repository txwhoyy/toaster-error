## What this is

A toaster that finally says out loud what it has been thinking every
morning. No bread puns, no crumb jokes — just a small kitchen appliance
confessing to the burnt slice, then quietly noting that its owner keeps
pressing the exact same button and hoping for a different breakfast. The
joke lands on the relationship: the machine did its job, the human did
the same thing again, and only one of them is surprised.

The program is a short, deterministic Python script. It writes exactly one
line — the error message above, 79 characters — to `/output/entry.txt`,
with no trailing newline, so the judged text is exactly that line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
